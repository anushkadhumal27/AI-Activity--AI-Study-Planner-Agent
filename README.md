# 🤖 AI Study Planner Agent

An AI-powered study assistant that creates personalized study plans,
tracks progress, reschedules missed sessions, and provides study guidance.

## 🚀 Modules

### 📅 Module 1 – AI Study Plan Generator
Creates a personalized timetable based on:
- Subjects
- Exam days remaining
- Available study hours

### 📊 Module 2 – Progress Tracker
Automatically tracks completed sessions and calculates:
- Overall progress
- Subject-wise progress

### 🔄 Module 3 – AI Missed Session Rescheduler
When a student misses a session, the AI analyzes the existing plan
and creates an updated schedule.

### 💬 Module 4 – AI Study Assistant
Answers student questions using their saved study plan, progress,
and study information.

## 🧠 Agentic Behavior

The system can:

`PLAN → REMEMBER → TRACK → ADAPT → ASSIST`

## 🛠️ Technologies

- Python
- Streamlit
- GroqCloud API
- AI Language Model
- python-dotenv
